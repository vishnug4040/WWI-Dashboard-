📊 WWI Power BI Dashboard

An interactive Power BI dashboard created to analyze and visualize Worldwide Importers (WWI) business data. The dashboard provides insights into profit, sales territories, employees, products, and performance trends.

🔍 Dashboard Highlights
💰 Profit Analysis – Track total profit and profitability trends.
🌎 Regional Analysis – Visualize profit distribution across different regions.
📍 Sales Territory Analysis – Compare profit performance across sales territories.
👨‍💼 Employee Analysis – Analyze profit and total sales generated by employees.
📦 Product Analysis – Identify key products contributing to business performance.
📈 Profit Trends – Monitor changes in profit over time.
🗓️ Date Filter – Interactively filter the dashboard based on selected dates.
🛠️ Tools Used
Power BI
Power Query
DAX
Data Visualization

🎯 Objective

The main objective of this dashboard is to transform WWI business data into clear and interactive visual insights, helping users understand sales performance, profitability, regional contribution, and employee performance.
